# Distributed Computing for DevOps

Course repository for distributed computing practice in the DevOps track at ITMO.

## Purpose

The repository collects practical coursework around distributed systems concepts that are useful for DevOps and infrastructure engineering: service interaction, reliability basics, deployment assumptions and operational thinking around distributed applications.

## Portfolio positioning

This repository is not positioned as commercial production experience. It is a supporting academic project that shows exposure to distributed computing topics during the DevOps-oriented master program.

Use it as a secondary portfolio link, after stronger infrastructure projects such as:

- Kubernetes GitOps VKR project with Argo CD and Flux CD.
- Docker Compose / CI / Trivy project.
- Kittygram CI/CD infrastructure project.
- PostgreSQL / DBOps project.

## Relevant skills

- Distributed systems basics
- DevOps-oriented application runtime context
- Infrastructure-aware debugging mindset
- Academic project documentation

## Notes for reviewers

For the strongest DevOps signal, start with the GitOps, Docker/CI and DBOps repositories. This repository provides additional background from the ITMO DevOps curriculum.
